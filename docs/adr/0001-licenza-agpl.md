# Licenza AGPL-3.0 invece di MIT

EduTime Pro è diventato repository pubblico su GitHub il 15/8/2026. Abbiamo scelto la licenza AGPL-3.0 invece di MIT per impedire fork commerciali chiusi (anche via SaaS) senza restituire le modifiche alla community; MIT è stata scartata proprio perché lo avrebbe permesso. Resta aperta la possibilità di dual licensing in futuro per chi vuole integrare il codice in un prodotto proprietario.
